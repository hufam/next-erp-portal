업무 메뉴

ERP 통합 메뉴 사용설명서

1. 접속 및 로그인

안내받은 ERP 접속주소를 즐겨찾기에 등록합니다. 사번과 비밀번호를 입력하여 로그인합니다.

2. 업무 메뉴

사용 권한이 있는 업무 메뉴를 선택합니다. WEB 사용 가능은 실행할 수 있는 메뉴이며 준비 중은 실행할 수 없습니다. PC에서는 업무별 탭, 모바일에서는 현재 탭에서 열립니다.

3. 업무 처리

각 모듈의 조회·등록·수정 기능을 사용합니다. 저장 전 내용을 확인하고, 작업 완료 후 목록으로 돌아갑니다.

4. 비밀번호 관리

로그인 후 비밀번호 변경을 이용합니다. 분실 시 로그인 화면의 비밀번호관리를 이용하고 등록 이메일을 확인합니다. 초기 비밀번호는 최초 접속 후 변경하십시오.

5. 로그아웃 및 문의

공용 PC에서는 작업 후 로그아웃합니다. 접속 불가 또는 권한 문의는 회사 담당자에게 요청합니다.
